## 🚀 How to Deploy on GitHub Pages

### Method 1: Direct Upload

1. Go to [GitHub](https://github.com) and create a new repository
2. Name it `tehsimshaikh.github.io` (or any name)
3. Upload all files from this folder
4. Go to **Settings** → **Pages**
5. Select **Deploy from a branch** → **main** → **/(root)**
6. Click **Save**
7. Your site will be live at `https://tehsimshaikh.github.io`

### Method 2: Using Git Commands

```bash
# Initialize git repository
git init

# Add all files
git add .

# Commit changes
git commit -m "Initial website upload"

# Add remote repository (replace with your repo URL)
git remote add origin https://github.com/tehsimshaikh/tehsimshaikh.github.io.git

# Push to GitHub
git push -u origin main
```

### Method 3: GitHub Desktop

1. Download [GitHub Desktop](https://desktop.github.com)
2. Add this folder as a new repository
3. Publish to GitHub
4. Enable GitHub Pages in repository settings
